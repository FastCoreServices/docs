---
title: "Instalacion Bezsel"
---

1. En el VPS, por SSH:

```text
ssh fastcore@46.224.49.168
sudo mkdir -p /opt/beszel
sudo chown fastcore:fastcore /opt/beszel
cd /opt/beszel
```

Crea `docker-compose.yml` solo con el hub. El agente va después, cuando el hub te dé la clave:

```text
services:
  beszel:
    image: henrygd/beszel:latest
    container_name: beszel
    restart: unless-stopped
    environment:
      APP_URL: http://localhost:8090
    ports:
      - 127.0.0.1:8090:8090
    volumes:
      - ./beszel_data:/beszel_data
      - ./beszel_socket:/beszel_socket
```

```text
docker compose up -d
docker compose ps
```

Tiene que salir `beszel` en marcha y el puerto solo en `127.0.0.1:8090`. No añadas el 8090 al firewall de Hetzner.

2. En tu PC, deja esa sesión y abre el túnel:

```text
ssh -L 8090:127.0.0.1:8090 fastcore@46.224.49.168
```

Entra en [http://localhost:8090](http://localhost:8090) y crea el usuario admin. El primero que se registre es el dueño del panel; usa una contraseña larga.

3. En el panel, Add system. En Host / IP pon exactamente:

```text
/beszel_socket/beszel.sock
```

Copia la clave pública y el token que muestra el diálogo. Vuelve a `/opt/beszel/docker-compose.yml` y añade el agente, pegando esos dos valores:

```text
beszel-agent:
  image: henrygd/beszel-agent:latest
  container_name: beszel-agent
  restart: unless-stopped
  network_mode: host
  volumes:
    - ./beszel_agent_data:/var/lib/beszel-agent
    - ./beszel_socket:/beszel_socket
    - /var/run/docker.sock:/var/run/docker.sock:ro
  environment:
    LISTEN: /beszel_socket/beszel.sock
    HUB_URL: http://localhost:8090
    KEY: "PEGA_AQUI_LA_CLAVE"
    TOKEN: "PEGA_AQUI_EL_TOKEN"
```

```text
docker compose up -d
```

El sistema tiene que pasar a online en el panel y mostrar CPU, disco y los contenedores. El socket de Docker va en solo lectura para que Beszel vea los contenedores; no lo montes en el hub.

Cuando Digi te cambie la IP, el panel se cae junto con el SSH: actualizas la regla del 22 y el túnel vuelve a funcionar. Si al añadir el sistema el panel no lo marca online, dime qué pone el diálogo y lo vemos.
